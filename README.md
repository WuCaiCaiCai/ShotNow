# ShotNow

一个 Android 悬浮球截图小工具：点一下悬浮球，拖出矩形，松手自动复制到剪贴板。

## 功能

- 半透明磨砂悬浮球，可拖动，自动记住位置
- 应用内调节悬浮球大小，运行中立即生效
- 截图时整屏变灰，框选区域保持原色
- 松手立即复制，没有确认步骤
- 不需要每次授权屏幕录制
- 无网络权限，截图只在本地处理

## 下载与安装

从 [Releases](https://github.com/WuCaiCaiCai/ShotNow/releases) 下载最新的 `ShotNow-vX.Y.Z.apk`。

- 支持 Android 11 及以上
- 首次安装需要允许「安装未知来源应用」

## 首次使用

1. 打开 ShotNow。
2. 点「去授予悬浮窗权限」，开启「显示在其他应用上层」。
3. 点「去开启无障碍截图」，找到「ShotNow 截图服务」并开启。
   - 如果开关是灰色或提示「受限设置」：到「系统设置 → 应用 → ShotNow → 右上角菜单 → 允许受限设置」后再开。
4. 回到 ShotNow，点「开启悬浮球」。
5. 点悬浮球 → 屏幕变灰 → 拖出矩形 → 松手。
6. 去任意输入框或聊天窗口粘贴。

## 使用说明

- 拖动悬浮球可以移动位置，松手后自动保存。
- 在首页的「悬浮球大小」里可以调整尺寸，运行中拖动立即生效。
- 框选过程中按返回键可以取消。
- 选区太小会提示重新拖动。

## 常见问题

**为什么第一次要开无障碍？**

Android 10 之后普通应用不能直接截屏。无障碍截屏不需要每次弹出「录制屏幕」授权，开一次即可长期使用。

**为什么截图里没有悬浮球？**

点球后会先隐藏悬浮球再抓取画面。

**为什么某些页面截出来是黑的或失败？**

银行、视频等应用启用了 `FLAG_SECURE` 防截屏，系统会阻止截图。

**怎么关闭悬浮球？**

在 ShotNow 首页点「关闭悬浮球」，或在通知里点「停止」。

## 隐私

- 应用没有申请网络权限，不会上传任何内容。
- 截图只写入本机缓存，并通过只读 URI 放进剪贴板；缓存 1 小时后清理。
- 无障碍权限仅用于截屏，不读取窗口文字或其他内容。
