# ShotNow

一个 Android 悬浮球截图小工具：点一下悬浮球，拖出矩形，松手自动复制到剪贴板。

## 功能

- 可拖动悬浮球，自动记住位置
- 可调大小和透明度，运行中立即生效
- 5 种低饱和主题色，球和界面一起变
- 截图时整屏变灰，框选区域保持原色
- 松手立即复制，没有确认步骤
- 不需要每次授权屏幕录制
- 可选「仅 S Pen 框选」，避免手掌误触
- 可选无障碍掉线自动恢复
- 无网络权限，截图只在本地处理

## 下载与安装

从 [Releases](https://github.com/WuCaiCaiCai/ShotNow/releases) 下载最新的 `ShotNow-vX.Y.Z.apk`。

- 支持 Android 11 及以上
- 首次安装需要允许「安装未知来源应用」

## 首次使用

1. 打开 ShotNow。
2. 点「悬浮窗权限」那一行，开启「显示在其他应用上层」。
3. 点「无障碍服务」那一行，找到「ShotNow 截图服务」并开启。
   - 如果开关是灰色或提示「受限设置」：到「系统设置 → 应用 → ShotNow → 右上角菜单 → 允许受限设置」后再开。
4. 回到 ShotNow，打开「悬浮球」开关。
5. 点悬浮球 → 屏幕变灰 → 拖出矩形 → 松手。
6. 去任意输入框或聊天窗口粘贴。

## 外观

- 「大小」和「透明度」会实时预览，松手后保存。
- 「主题色」提供焦糖橙、松石绿、雾蓝、砖红、石墨五种，球、开关、滑块和框选角标会一起变色。
- 透明度最低 20%，数值越低越淡，但仍然可以点按。
- 拖动悬浮球可以放到屏幕任意位置。

## 仅 S Pen 框选

在「行为」里打开「仅 S Pen 框选」后：

- 截图时只识别 S Pen 画框，手指和手掌误触会被忽略。
- 悬浮球仍然可以用手点按和拖动。
- 框选提示会变成「仅 S Pen 可框选」。

适合做题、批注时一边用笔一边用手扶平板的情况。

## 自动修复无障碍（可选）

如果系统经常关掉无障碍服务，可以给 ShotNow 授一次 `WRITE_SECURE_SETTINGS`，让它在掉线时尝试自动恢复。

1. 手机/平板连电脑，打开 USB 调试。
2. 在电脑上执行：

```bash
adb shell pm grant com.shotnow android.permission.WRITE_SECURE_SETTINGS
```

3. 回到 ShotNow，点「自动修复」那一行可以复制上面的命令，状态变成「已授权」即成功。
4. 授权一次即可，之后可以关闭 USB 调试和开发者选项。
5. 卸载重装后需要重新授权；手动撤销权限也会失效。

授权后打开「掉线自动恢复」，无障碍被系统关闭时，ShotNow 会在点球或回到 App 时尝试重新打开。

## 常见问题

**为什么第一次要开无障碍？**

Android 10 之后普通应用不能直接截屏。无障碍截屏不需要每次弹出「录制屏幕」授权，开一次即可长期使用。

**为什么截图里没有悬浮球？**

点球后会先隐藏悬浮球再抓取画面。

**为什么某些页面截出来是黑的或失败？**

银行、视频等应用启用了 `FLAG_SECURE` 防截屏，系统会阻止截图。

**为什么手指画不出框？**

检查「行为 → 仅 S Pen 框选」是否打开。打开时只认 S Pen。

**怎么关闭悬浮球？**

在 ShotNow 首页关闭「悬浮球」开关，或在通知里点「停止」。

## 隐私

- 应用没有申请网络权限，不会上传任何内容。
- 截图只写入本机缓存，并通过只读 URI 放进剪贴板；缓存 1 小时后清理。
- 无障碍权限仅用于截屏，不读取窗口文字或其他内容。
- 自动修复权限只用于写入无障碍开关，不读写其他系统设置。
